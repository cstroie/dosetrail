# Dozimetrix branding

- **Name:** written *Dozimetrix* in text and UI (since 2026-11-24: the Romanian *dozimetrie*, and *-rix*, the Gaulish "king" of Vercingetorix — an Asterix nod in words only, never in imagery); `dozimetrix` for the package, command and repository; `DOZIMETRIX` as the default DICOM AE title.
- **Mark:** the "D-curve": a D whose bowl holds a rising dose curve (the running Ka,r), centred in the bowl (option A of `logo-options-dozimetrix.png`, chosen 2026-11-24; the earlier curve was a single peak). A single stroke on a 24-unit grid (`assets/img/logo-mark.svg`, `currentColor`); the favicon puts it on the dark tile (`assets/img/favicon.svg`). Stroke width 2–2.4 depending on size; it stays legible at 16 px.
- **Wordmark:** "Dozimet**rix**" with "rix" in the accent colour of the palette in use (Film: #9CB8D6 on dark, #2F5A86 on light); the rest in the text colour.
- **Palette "Iodine"** (`assets/css/tokens.css`): soft violet accent #AE99D6 on near-neutral graphite (bg #111114, panel #18171B) in the dark theme; #674994 on white / #EEECF1 in the light theme. The favicon uses Film's colours (tile #070B0E, mark #9CB8D6). Status stays green / amber / red (WCAG AA on every panel).
- **Chart series:** a fixed 8-colour order (blue, orange, aqua, yellow, magenta, green, violet, red), stepped separately for dark and light; checked with the dataviz palette validator on both panels: adjacent CVD ΔE ≥ 8.4, normal-vision ΔE ≥ 19.3. Three light-mode slots sit below 3:1 on white, so charts keep legends and tooltips. The former series failed the colour-vision check (pink next to teal, ΔE 1.2–3.9).
- `palette-options.png`: the palettes considered (current cyan, Iodine, Phosphor, Instrument), dark overview, dark charts and light overview.
- `logo-options.png`: the three concepts considered (gauge, beam cross, D-curve).
- **Palettes, chosen per browser** (the Appearance menu in the top bar, next to dark / light): *Film* (the default since 2026-11-22), *Iodine*, *Cherenkov* (the former cyan, a reactor pool's glow), *Phosphor* (chartreuse, a dosimeter's glow; "ok" turns teal). *Film* is after Reporion's: cool X-ray film on a light box, with its own softer status steps and a light-box glow behind the page; it replaced *Instrument*, a stored choice of which carries over). Each has dark and light steps in `tokens.css` (`:root[data-palette=…]`); `boot.js` applies the stored choice before the first paint. All four share the validated chart series and the status colours; every text, accent and status token clears WCAG AA on its panel.
